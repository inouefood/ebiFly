ebiFly ver 2.0 リニューアル案

とばせ！えびフライ

2019年版をまるごと作り直す案です。えびを作って、衣をつけて、揚げて、ソースをふって、空へ飛ばす。5つのステップはそのままに、イラストを全部描き直し、空では障害物をよける操作を足しました。下のスマホはそのまま遊べます。

App Store 削除予告への対応 3年以上更新がないアプリとして、通知から90日以内に更新が承認されないと削除されます。最新Xcodeでビルドした2.0を提出すれば掲載は続きます。
削除予告→2.0 を提出→掲載継続

遊んでみる

右のリストから好きな画面に飛べます。実機ではシェイクは端末をふる操作、Webでは連打で代用しています。

全画面

8画面のストーリーボード。横にスクロールできます。

イラスト刷新

手描きのラフな線を、太めの茶色い輪郭と丸いパーツでそろえ直しました。えびは「しっぽ＋からだの玉」をつなげる構造なので、ゲーム内の物理ジョイントとそのまま対応します。

2.0 で変えること

審査で「作り直された最新のアプリ」と伝わるように、見た目と中身の両方を更新します。

技術面

  • 必須
    最新 Xcode / iOS 17 SDK 以上でビルドarmv7 指定と古い Main.storyboard を削除し arm64 のみに
  • 必須
    SwiftUI のアプリ構成 + SpriteKit（SpriteView）AppDelegate＋xib 構成から移行。全画面サイズとiPadに対応
  • 必須
    メインスレッドの sleep(1) を削除揚げ・ソース画面で約1秒フリーズしていた原因。SKAction の待機に置き換え
  • 必須
    シェイク判定を作り直し加速度の整数部比較で誤判定していた処理を、加速度の大きさのしきい値判定に
  • 改善
    縦画面固定、Timer 遷移を SKAction に統一横向きでレイアウトが崩れていた問題を解消
  • 改善
    Core Haptics の振動、プライバシーマニフェスト追加

体験面

  • 新規
    揚げ加減ミニゲームメーターを止めてきつね色を狙う。飛距離に最大1.5倍
  • 新規
    障害物よけの飛行パート傾けて鳥・飛行機・いん石をよける。ぶつかったらそこまで。高度で空の色も変わる
  • 新規
    称号・きろく画面・しっぽコレクション3,000mで王冠しっぽを解放。くり返し遊ぶ目標に
  • 新規
    Game Center ランキング
  • 改善
    全イラスト・アイコン描き直し、操作ヒントを各画面に
  • 改善
    結果のお弁当に自分のえびが入る作ったえびの形・揚げ色がそのまま反映
このあとの進め方
  1. このページで見た目と遊びの流れを確認・修正
  2. Swift（SwiftUI + SpriteKit）で 2.0 を実装、新イラストを @2x/@3x PNG に書き出して差し替え
  3. スクリーンショット・説明文を更新して審査に提出（90日の期限内）
